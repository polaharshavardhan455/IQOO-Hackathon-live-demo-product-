Runs the router on queries it was not trained on. Small test set written by the author, so treat the number as a smoke test, not a benchmark.

What is real here: the clause splitting, the nearest-centroid router (TF-IDF in this web demo; MiniLM sentence embeddings in the Android app), the masking, and the byte counts. What is simulated: the local language model replies (canned, written for the demo) and the web results (placeholders). City names are kept in the outgoing query because the answer needs them.
